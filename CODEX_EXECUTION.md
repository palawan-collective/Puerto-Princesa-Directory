# IslaVista — local Codex implementation contract

## Mission and workspace
Build a first-class working tourism webapp in a fresh local folder named islavista. This is a working name, not a verified brand or domain. Use the supplied source as a starting point, not an existing external project. Work entirely in Codex local workspace and its browser preview. Do not publish, deploy, create accounts, connect external projects, or perform remote repository operations. Do not export the finished application until the user approves the preview. Use local persistent data and media; no cloud credentials required. Puerto Princesa is the first public-facing destination.

## Stage 3: mapping — agreed stack, no experimentation
Leaflet 1.9.4 + Leaflet.markercluster 1.5.x. Street default to match approved design. Four layers enabled in UI:
| Layer | URL | Zoom |
|---|---|---|
| Street | https://tile.openstreetmap.org/{z}/{x}/{y}.png | native/display 19 |
| Dark | same OSM URL | native/display 19; apply only to tile pane: invert(1) hue-rotate(180deg) brightness(.72) contrast(.92) saturate(.6) |
| Satellite | https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x} | native 17, display 19 |
| Terrain | https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png | subdomains abc, native/display 17 |
Preserve correct attribution, network-error states and provider-configurable endpoints; no bulk tile download or proxy cache violating terms. Check provider terms/capacity before public production launch (open-source engine does not mean all tile services are unrestricted). Do not arbitrarily disable layers in development. Use real raster tiles, never synthetic map as a substitute. Switching layers retains center/selection and clamps zoom only when required. GPS permission prompt on user action, accuracy indicator, fallback when denied; zoom +/-; fullscreen; search this area; real coordinates; directions link; clustering with chunked loading and category-colored Lucide SVG pin markers. Map and list share filter/query state. Do not invent missing coordinates, hide or flag unmapped records. Invalidate map size after panel/layout changes; test touch pinch/pan, zoom, tile switches and map lifecycle. No gray tiles from requesting satellite zoom above native cap. Record genuine tile load success/errors in tests.
